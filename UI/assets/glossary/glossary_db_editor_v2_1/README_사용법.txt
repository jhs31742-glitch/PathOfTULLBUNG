Path of TULLBUNG 용어집 DB 편집기 v2.1

1. index.html 파일을 Microsoft Edge 등 브라우저에서 직접 엽니다.
2. 상단 JSON 불러오기를 눌러 실제 glossary_db.json 파일을 읽습니다.
3. 왼쪽은 인게임 화면과 유사하게 용어 검색·분류별 목록만 표시합니다.
4. 상단 두 번째 도구 줄에서 모든 분류 / 인게임 목록 / 순서 편집 / 정렬 기준 / 정렬을 order에 적용을 사용할 수 있습니다.
5. 인게임 목록은 DB의 실제 분류별 목록을 표시합니다.
6. 순서 편집에서 현재 order 순서를 선택하고 검색·분류 필터를 해제하면 드래그와 ▲▼ 이동이 활성화됩니다.
7. 정렬 기준에서 이름·분류·태그 순서를 선택하면 화면만 바뀝니다. 정렬을 order에 적용을 눌러야 DB order 숫자가 변경됩니다.
8. 중앙 카드의 용어명·요약·본문을 직접 편집하고, 관련 용어를 추가·제거합니다.
9. DB JSON 내보내기를 눌러 게임과 호환되는 파일을 다운로드합니다.
10. 다운로드한 JSON을 검토 및 백업한 뒤 게임의 assets/glossary/glossary_db.json에 배치합니다.

주의: 브라우저는 원본 DB를 자동으로 덮어쓰지 않습니다. 이 편집기는 게임용 HTML과 DLL을 변경하지 않습니다.
