# Path of TULLBUNG

Private Dev0.9 Stage20 snapshot, version 0.9.0.

The root contains the Native source, CMake configuration, and Prisma UI source. The mod/ directory contains the verified Dev0.9 deployment files, including the plugin, ESP, UI, meshes, and textures.
The CMake configuration records the existing local SDK layout. Building on another machine requires locating the pinned CommonLibSSE-NG and vcpkg dependencies and adapting that layout.
User fonts, installed dependencies, saves, profiles, logs, and work archives are outside this snapshot.
The preceding F6 build passed user Skyrim QA. The deployed 0.9.0 changes await in-game verification.
